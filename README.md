# Педконсилиум — электронная очередь родительского собрания

Интерфейс на казахском языке. Сайт без внешних зависимостей: Node.js ≥ 18 и папка `public/`. Устанавливать ничего не нужно.

При входе родитель указывает своё имя, а также имя и класс ребёнка. Учитель видит это в очереди и в карточке текущего посетителя.

## Размещение в облаке: Render.com (бесплатно, через GitHub)

Vercel для этого сайта не подходит. Он запускает код короткими «вспышками» (serverless) и не может держать общую очередь в памяти и постоянное соединение с телефонами. Render работает так же просто, через GitHub, но держит настоящий сервер и сразу даёт HTTPS.

1. **GitHub:** создайте новый репозиторий, например `pedkonsilium`, и загрузите в него **содержимое** этой папки (Add file → Upload files). В корне репозитория должны лежать `server.js`, `package.json`, `render.yaml`, папки `public/` и `lib/`.
2. **Render:** зайдите на https://render.com → Sign in with GitHub.
3. **New → Blueprint** → выберите репозиторий → Apply. Render сам прочитает `render.yaml` (бесплатный тариф, PIN 2026).
   Вручную тоже можно: New → Web Service → репозиторий → Runtime: Node, Build: `npm install`, Start: `node server.js`, Instance type: Free.
4. Через 1–2 минуты появится адрес вида `https://pedkonsilium.onrender.com`.
5. Откройте `https://…onrender.com/qr` → «Басып шығару» → повесьте плакат с QR-кодом у входа.

**Изменения:** загружаете исправленный файл в GitHub, и Render сам обновляет сайт.
**PIN-код, предметы, учителя:** в файле `config.json` (см. ниже).

Особенности бесплатного тарифа:
* Без посетителей сервер «засыпает» через 15 минут, первое открытие потом занимает около минуты. **Откройте сайт за 5–10 минут до собрания.** Во время собрания он не уснёт.
* При перезапуске или обновлении очередь обнуляется. Не загружайте изменения во время собрания.

## Предметы, учителя, PIN — файл `config.json`

```json
{
  "pin": "2026",
  "minutes": 5,
  "teachers": [
    { "subject": "Қазақстан тарихы", "teacher": "" },
    { "subject": "Алгебра",          "teacher": "Сапарова А.Б." },
    { "subject": "Алгебра",          "teacher": "Жұмабеков Е.С." },
    { "subject": "Физика",           "teacher": "" }
  ]
}
```

* Каждая строка в `teachers` — **отдельная очередь**. Если предмет ведут 2–3 учителя, добавьте строку на каждого: родитель увидит «Алгебра · Сапарова А.Б.» и «Алгебра · Жұмабеков Е.С.» отдельно.
* `teacher` можно оставить пустым (`""`), тогда показывается только предмет.
* `pin` — PIN-код учителей, `minutes` — длительность приёма.
* Правила записи: каждое значение в двойных кавычках `"..."`, между строками запятая, **после последней строки запятой нет**. Если в файле ошибка, сайт не запустится, а в журнале (Render → Logs) будет написано «ОШИБКА в config.json».

### Как внести изменения на сайт (GitHub + Render)

1. Откройте репозиторий на github.com → файл `config.json` → значок карандаша ✏️ (Edit).
2. Исправьте, нажмите **Commit changes**.
3. Render сам обновит сайт за 1–2 минуты (вкладка Events → «Deploy live»).

Так же меняется любой другой файл. Можно и загрузить несколько файлов сразу: **Add file → Upload files**, и файлы с теми же именами заменятся.
⚠️ При каждом обновлении очередь обнуляется, поэтому не вносите изменения во время собрания.

## Звуки (`public/`)

* `notification.mp3` — вызов родителя. **Замените своим файлом с тем же именем.**
* `warning.mp3` — «скоро ваша очередь» у родителя и «осталась 1 минута» у учителя.
* `bell.mp3` — звонок у учителя, когда 5 минут истекли.

## Как решена проблема звука на телефонах

Браузеры iOS и Android не дают сайту играть звук в фоне и при погашенном экране, поэтому решение многослойное:

1. **Экран не гаснет:** Screen Wake Lock API (iOS 16.4+, Android Chrome), для старых iOS — запасной вариант с беззвучным зацикленным видео. Пока страница открыта, звук приходит гарантированно.
2. **Разблокировка звука при первом касании:** звуки «прогреваются» на кнопке «Продолжить». После перезагрузки страницы появляется одна кнопка «Включить звук».
3. **iOS и переключатель «Без звука»:** `navigator.audioSession = 'playback'` (iOS 17+) и воспроизведение через `<audio>`.
4. **Восстановление после блокировки:** при возвращении на страницу данные сразу запрашиваются снова, баннер и звук срабатывают. Если браузер снова заблокировал звук, он сыграет при первом касании экрана.
5. **Дублирование сигнала:** вибрация (Android), мигающий заголовок вкладки, системное уведомление (Android, когда вкладка в фоне). Звук вызова повторяется каждые 10 секунд, пока родитель не нажмёт «Иду ✓» (не более 6 раз). Кнопка — «Барамын ✓».
6. **Блок «Проверить звук»** в кабинете родителя показывает статус: звук, экран, уведомления.

Ограничение: если родитель полностью закроет браузер или заблокирует iPhone на старой iOS, ни один сайт его не «разбудит». Для этого нужны Web Push и установка сайта на главный экран — это возможное следующее улучшение.

## Логика очереди

* «Перед вами» = место в списке + 1, если у учителя уже сидит посетитель.
* Плашка «СКОРО ВАША ОЧЕРЕДЬ!» появляется, когда перед вами 1 человек (или вы первый, а учитель свободен).
* Если родитель сейчас сидит у другого учителя, кнопка «Пригласить следующего» пропускает его, но **сохраняет ему место**. Учитель видит метку «сейчас у учителя: Физика».
* Родитель, который вошёл с тем же ФИО на другом телефоне, получает свои записи обратно.
